Tutorial Lengkap Hosting Website di GitHub

Ubah file HTML, CSS, dan JavaScript kamu menjadi website online dengan link HTTPS secara gratis, langsung dari browser HP!

</>
Website kamu, online!HTML · CSS · JavaScript
✓

Ikuti 5 langkah berikut

Estimasi 5–15 menit, tergantung koneksi dan ukuran file.

1

Buat atau login akun GitHub

Buka github.com melalui Chrome di HP. Daftar jika belum punya akun, atau login jika sudah punya.

GitHub · Mulai di sini

Platform untuk menyimpan kode dan menerbitkan website statis.

Sign upLog in
💡
Tips: Gunakan email yang bisa kamu akses. Simpan username karena akan menjadi bagian dari link website.
2

Buat repository baru

Buka halaman github.com/new untuk membuat tempat menyimpan file website.

Pengaturan yang disarankan
  • Repository name: websiteku (nama bebas)
  • Pilih Public agar mudah diterbitkan lewat GitHub Pages gratis.
  • Centang Add a README file (opsional, tapi membantu).
  • Tekan Create repository.

Hindari memasukkan kata sandi, token rahasia, atau data pribadi ke repository publik.

3

Upload file website

Di halaman repository, pilih Add file → Create new file. Beri nama file utama index.html, tempel kode HTML, lalu pilih Commit changes.

index.html · contoh minimal
<!doctype html>
<html lang="id">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Website Saya</title>
</head>
<body>
  <h1>Halo! Website saya sudah online 🎉</h1>
  <p>Diterbitkan gratis dengan GitHub Pages.</p>
</body>
</html>

Kalau CSS dan JS berada di file terpisah, upload juga, misalnya style.css dan script.js, lalu pastikan nama dan jalurnya sesuai dengan kode HTML.

📱
Untuk file yang sudah ada di HP, buka Add file → Upload files jika tersedia. Pilih file dari penyimpanan, lalu commit perubahan. Untuk banyak file sekaligus, unggah satu per satu atau gunakan komputer jika lebih praktis.
4

Aktifkan GitHub Pages

Buka tab Settings pada repository, cari Pages, lalu atur sumber penerbitannya.

Settings → Pages
Build and deployment
Source: Deploy from a branch ▾
Branch
main ▾/ (root) ▾Save
  • Source: Deploy from a branch
  • Branch: main
  • Folder: /(root) jika index.html ada di folder utama.
  • Tekan Save.

Jika file utama kamu berada di folder /docs, pilih folder itu hanya jika memang struktur proyekmu menggunakannya.

5

Dapatkan link HTTPS

Tunggu beberapa menit hingga proses deployment selesai. Buka kembali Settings → Pages, lalu tekan Visit site jika sudah muncul.

GitHub Pages · Your site is live

✓ Your site is published at:

https://username.github.io/websiteku/
Visit site ↗

Link biasanya berbentuk seperti contoh di atas. Ganti username dengan username GitHub dan websiteku dengan nama repository kamu.

🔒
HTTPS disediakan oleh GitHub Pages. Jika link belum bisa dibuka, tunggu sebentar dan periksa kembali status deployment.
✓

Selesai! Website siap dibagikan

Masukkan username dan nama repository kamu untuk menyusun link perkiraan. Ini hanya membuat contoh URL, bukan memeriksa apakah website sudah diterbitkan.

https://username.github.io/websiteku/
Pastikan URL yang dihasilkan sama dengan alamat di menu Pages sebelum membagikannya.
Yang kamu dapat
  • Hosting website statis gratis.
  • Link HTTPS yang bisa dibagikan.
  • Bisa memperbarui website kapan saja dengan mengedit dan commit file.

FAQ — pertanyaan umum

Jawaban singkat untuk masalah yang sering muncul.

Apakah benar-benar gratis?

GitHub Pages menyediakan hosting gratis untuk situs statis pada batas dan ketentuan layanan GitHub. Kamu tidak wajib membeli domain sendiri.

Kenapa muncul 404 / halaman tidak ditemukan?

Periksa apakah file bernama tepat index.html, berada di folder sumber yang dipilih, dan perubahan sudah di-commit. Pastikan URL dan nama repository benar.

Apakah bisa menghosting PHP atau database?

GitHub Pages hanya untuk konten statis. PHP yang perlu dijalankan di server, backend, dan database server memerlukan layanan lain.

Bagaimana cara memperbarui website?

Edit atau upload ulang file di repository, lalu commit perubahan. GitHub Pages akan membangun ulang situs secara otomatis.

Apakah teman bisa melihat kode saya?

Jika repository bersifat publik, orang lain dapat melihat kode sumbernya. Jangan simpan password, API key rahasia, atau data sensitif di dalamnya.

Bisakah memakai domain sendiri?

Bisa, jika kamu memiliki domain. Namun itu opsional; subdomain github.io gratis sudah cukup untuk membagikan website.

Tips supaya website lancar

Checklist sebelum membagikan link ke teman.

📁
Periksa struktur file

Nama file, huruf besar-kecil, dan jalur CSS/JS harus cocok dengan referensi di HTML.

📱
Uji di HP

Buka link di Chrome Android dan cek tampilan di layar kecil serta tombol-tombolnya.

🔐
Jaga informasi rahasia

Repository publik bukan tempat menyimpan password, token, atau data pribadi.
